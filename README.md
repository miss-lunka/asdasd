# DAUYS

Kazakh voice cloning studio (prototype). The interface runs with Gradio. Real voice cloning requires a compatible hosted TTS model configured via `VOICE_API_URL` and optionally `VOICE_API_NAME`; no model backend is connected yet. Emotion annotations are previews, not synthesis controls.

Only upload voice samples you own or are authorized to use.
